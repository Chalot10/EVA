# Changelog

Todas as alterações notáveis neste projeto serão documentadas neste ficheiro.

O formato é baseado em [Keep a Changelog](https://keepachangelog.com/pt-PT/1.0.0/),
e este projeto adere ao [Semantic Versioning](https://semver.org/lang/pt/).

## [0.1.0] - 2026-10-15

### Adicionado
- Estrutura base do projeto EVA
- Sistema de reconhecimento de voz
- Sistema de síntese de voz
- Sistema de plugins modular
- Modo texto como fallback
- Documentação inicial

### Alterado
- Migração para Python 3.13
- Substituição de PyAudio por sounddevice

### Corrigido
- Loop infinito de erros no assistente
- Tratamento de erros no microfone
