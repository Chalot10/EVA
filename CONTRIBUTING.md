# Guia de Contribuição

Obrigado por considerares contribuir para o projeto EVA! 🎉

## Como Contribuir

1. Faz **fork** do repositório
2. Cria uma **branch** para a tua feature
3. Faz as tuas alterações
4. Faz **commit** seguindo Conventional Commits
5. Faz **push** para a tua branch
6. Abre um **Pull Request**

## Padrões de Código

- PEP 8
- Type hints
- Docstrings em português
- Testes unitários

## Reportar Bugs

Abre uma [issue](https://github.com/Chalot10/EVA/issues) com:
- Descrição do bug
- Passos para reproduzir
- Comportamento esperado
- Screenshots (se aplicável)
- Ambiente (SO, versão Python)
